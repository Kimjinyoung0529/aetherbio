가까운 목표 · Near

1. 문헌 길잡이

PubMed 등 공개 문헌을 한국어로 더 편하게 훑는 연구 보조 도구. BioBERT·BERN 계열 공개 모델을 참고해 NER·엔티티 정규화 데모부터. 검색 → 엔티티 하이라이트 → 짧은 한국어 요약 보조 흐름을 우선 스케치합니다.

범위. 진단·처방·임상 권고 아님. 문헌 탐색·요약·엔티티 표시만. 의료기기 아님.

  • dmis-lab/biobert (Korea Univ.)
  • dmis-lab/bern · BERN
  • 참고: PubMed / NCBI 공개 문헌 API
가까운 목표 · Near

2. 치료 벤치마크 스튜디오

Therapeutics Data Commons(TDC) 같은 AI-ready 공개 데이터셋·스플릿·벤치마크를 한국어 UX로 감싼 학습·평가 허브. 공정한 비교와 재현에 초점. 리더보드 UI·스플릿 고정·결과 카드 템플릿부터.

범위. 신약 후보를 “만든다/발견한다”고 말하지 않음. 공개 벤치 학습·평가·비교만.

  • mims-harvard/TDC
  • tdcommons.ai
먼 목표 · Aspirational

3. 표현형 비전 랩

공개 세포 현미경 이미지(예: RxRx3-core)로 비전 모델 벤치·교육 데모. 연구·학습용 샌드박스. GPU·스토리지·데이터 라이선스 확인이 선행되어야 해서 먼 목표로 둡니다.

범위. 임상 효능·진단 성능 주장 없음. 공개 벤치용 축소본·교육 데모만 검토.

  • Recursion · RxRx3-core 공개 안내
  • 관련: Hugging Face의 RxRx3-core 배포(공개 벤치용 축소본)

일하는 원칙

모회사 AETHERION과 같은 DNA — 정직·한국어 우선·Liquid Glass 감성.

공개 데이터만

라이선스 확인된 공개 데이터셋·오픈툴 위에서만 계획. 비공개 환자 데이터·무단 스크래핑 없음.

주장하지 않는 UX
